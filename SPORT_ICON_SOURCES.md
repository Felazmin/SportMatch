# Sport Icon Sources

Six SVG files in assets/figma/sport-*.svg are unmodified Material Design Icons
from Pictogrammers / Templarian MaterialDesign (Apache-2.0 icon license).
Colors are applied at runtime by the existing flutter_svg renderer.

Source: https://github.com/Templarian/MaterialDesign/tree/master/svg
License: https://github.com/Templarian/MaterialDesign/blob/master/LICENSE
Apache-2.0: https://www.apache.org/licenses/LICENSE-2.0

Mapping: sport-badminton -> badminton.svg; sport-soccer -> soccer.svg;
sport-basketball -> basketball.svg; sport-tennis -> tennis.svg;
sport-stadium -> stadium.svg; sport-paddle -> table-tennis.svg.
The last is a solid paddle-and-ball pictogram used for the Pickleball category,
not a claim that the source library supplies an official Pickleball symbol.
