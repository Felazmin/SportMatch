# Customer Forum UI

Entry: customer > Explore > Forum. Invitations open Cost & Schedule; tournament registration opens Tournament Detail, then the existing registration form and ticket workflow.

Search reads public posts, public groups, demo chat contacts and available events. No invented likes, comments, member names or totals are displayed.

Current data uses fixed event fees, one event session and doubles teams. It does not provide a shared rental pool, multi-day tournament agenda, insurance, friend requests, or a full-refund guarantee. The screens do not claim those unsupported features. Player suggestions open existing demo chats.

The calendar uses Flutter CalendarDatePicker and SDK Vietnamese localization. Navigation selects Explore; Account screens retain their original selected tab.
